# Decisions taken without asking (safe defaults)

The build ran unattended in a cloud session; wherever a step needed a user decision, the safe default below was taken.

| # | Decision | Why / how to change |
|---|----------|---------------------|
| 1 | **Projects root** for "+ New project" defaults to `~/alpha-omega-projects` (Windows: `%USERPROFILE%\alpha-omega-projects`). | Set `"projectsRoot"` in `.satoru/config.json` to change it. A folder that already exists is never overwritten (409). |
| 2 | **Git is optional.** If `git` is not installed (the user's PC has none), new projects are created without `git init`, and the Projects tab shows "no git" instead of a branch. | Install Git for Windows later and branches/clean-dirty appear automatically. |
| 3 | **Hooks are registered at project level only** (`.claude/settings.json`). User-level settings are never touched. | Optional user-level snippet is in the README. Double registration is de-duplicated by the hook. |
| 4 | **Placeholder art** generated by `scripts/make-placeholder-art.mjs`; each member gets an evenly spaced hue in card order. | Replace files in `raw/` and run `npm run assets`. |
| 5 | **Office layout** (placeholder map): the "corridor along the bottom" runs between the middle row and the bottom row (Lounge/Pantry open onto it), so Server Room can sit directly under Command Center and open into it. | Draw your own map and re-place everything with the picker (`/picker.html`). |
| 6 | **Server runs TypeScript via `tsx`** (no compile step) for both `dev` and `start`; `build` = typecheck. | Simplest for a Windows machine with only Node installed. |
| 7 | **Lead "Wake" button** injects a short prompt asking the lead to check the board — only when Claude is running in the embedded terminal. | Edit `web/src/components/Terminal.tsx`. |
| 8 | **Ambient wandering**: resting members change break spot roughly every 90 s (Lounge/Pantry only). This is idle ambience, not activity — work state only ever comes from real hook events. | Set the epoch in `web/src/lib/placement.ts` higher to calm it down. |
| 9 | **Branch**: work is on `build/alpha-omega` as requested; PR opened to `main`. | — |
| 10 | **Approval id** = `"A-" + md5(title + local date)[0..8]` → the same 🔔 line on the same day is never added twice. | — |
